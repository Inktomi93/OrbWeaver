Preset redesign — the Params deck

CONTENT = the deck: ONE flat tab level, one scrolling instrument column, kicker-separated clusters. Every knob is a KnobRow: label · slider · an editable mono number · reset. An unset knob shows its effective value ghosted with provenance — the datum is never hidden. Output/context are the SAME slider grammar at capability-fed integer ranges (round-3 ruling). Dotted underline = explanatory prose carried on hover (the hints→hover ruling) — only data stays visible. CONTEXT = the Params-view readout (effective profile · capability · mapping — per-view, spec §7). Knob set and ranges are the real userIntentSchema vocabulary.
