## 4. LIVE (57) — grouped by the PRODUCER SHAPE the lens is blind to

The lens's banner declares four blind spots (template-literal producers, same-named fields, brand phantom
symbols, spread producers). None of the 57 is any of those four. Six new shapes, in descending fixability:

### F1. Same-file readers are discarded, so a self-consumed schema reads as "NOTHING reads it" (8 hits)

`fieldHit` (`scripts/codemods/ast.ts:4638`) filters readers with
`.filter((fp) => !fp.endsWith(field.node.getSourceFile().getFilePath()))` — the whole declaring FILE, not
just the declaration node. A contracts file that declares a foreign wire schema and consumes it in its own
importer therefore prints the strongest possible tail ("the declaration is its only occurrence") about a
fully-live field.

### 5.3 LIVE → the lens-improvement note (one `work` issue, or a leg on #186's lane)

In priority order, with the hit count each retires:

1. **F1 same-file readers (8 hits) — `scripts/codemods/ast.ts:4638`.** Filter by declaration ANCESTRY,
   not by file path. Also stop printing "the declaration is its only occurrence" when the only reason is
   the file filter.
2. **F3 JSX `name="…"` + `setFieldValue("…")` producers (17 hits).** Index JSX string attributes named
   `name` and the first string-literal argument of `setFieldValue`, splitting on `.`. Note the corpus
   fence: the lens's project must include `.tsx` (it currently reports `langs=ts:94` for the contracts
   scan; the READER/PRODUCER index runs over the whole corpus, which does include tsx — verify before
   assuming).
3. **F2 element-access producers (5 hits).** `out["k"] = v` on the write side, mirroring what
   `consumedNamesOf` already does on the read side.
4. **F6 `.default()` self-producers (2 hits).** A zod field with a `.default()` populates itself.
5. **F4/F6 fences (25 hits) — the judgment call, not a patch.** Model-produced (tool `argsSchema`,
   `z.toJSONSchema` projections, `REFINERY_STAGE_PAYLOADS`) and wire-input-only schemas cannot be
   adjudicated by a key index. Recommend EXCLUDING them by derivation (a schema reachable from a tool
   registration or a router input) rather than reporting them, and saying so in the banner.
6. **Reader attribution wording.** "N site(s) spell this NAME" — the current "READ it" is a claim the
   index cannot support (two false consumers shown in §4).

With F1+F2+F3+F6.4 the run drops from 70 hits to 38; with the F4/F6 fences it drops to \~13, at which
point the two defects are 15% of the output instead of 3% and the lens is worth standing up as a
recurring pass.
