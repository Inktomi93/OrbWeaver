## Root investigation

- Reuse settings tracks before retuning dimensions. Automation uses a pane-wide vertical numeric field; Chat behavior uses bounded shared tracks.
- Keep full settings lessons in Context. The shared row deliberately retains a short registry-derived gloss.
- Distinguish necessary task instructions from duplicated explanations. Do not move every sentence into Context indiscriminately.
- Investigate composer grouping in the shared host. Preserve plugin attribution and distinguish writing, generation, media and plugin actions.
- Judge workflow continuity, recognition and action placement alongside aesthetics.
