## Coupled routing and enforcement boundary

The constitution's two gate routes already warned that the old exemplar review was refuted. The remaining unsafe
“copy these shapes” route was the legacy guide opener. Both constitution routes now distinguish final authoring from
the verbatim archive. Gate rules, the executor doctrine, tooling law, UI short-form route and program router use the
same distinction. No world/config rule or verification floor is weakened by replacing a legacy checklist.

The original path remains tracked for `gate-modernization` LAW/docRow and the two native fixture-ignore citations.
Guide §§1–4 explicitly route the meta-gate's legacy field/stale-arm advice to history; guide §6 retains the fixture grant's
actual rationale. Historical source comments remain provenance. They are not bulk-rewritten into invented final meanings.

Source review separated loader/runtime guarantees from bounded source-policing arms. The guide names each owner and
states limits for family semantics, analysis/execution honesty, unreadable proof/fix sources, assertion semantics,
private wrappers and real-corpus liveness. It does not claim all rows of the dated #2111 matrix are sealed.

The scaffold/source part of #2126 is separate: Q15 already reaches descriptor validation through the real loader and
runs declared conformance. Header completeness, mechanical family-choice behavior, production soundness coverage and a
runtime legacy-template negative require their own source/test disposition. The scaffold’s printed legacy-only
route and CLI descriptor wording also require the separately owned source correction. This documentation change does not claim
those controls were implemented or run.
