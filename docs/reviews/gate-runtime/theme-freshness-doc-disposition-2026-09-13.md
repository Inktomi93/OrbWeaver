## Accepted boundary

The owner ruled on 2026-09-13 to retain canonical `generateArtifacts` validation, including the token-removal
history requirement, for this baseline. Do not bypass validation or create another emitter to make a freshness
check succeed. This is acceptance of the implemented baseline with a stated limitation, not a requirement that
all future baselines acquire Git-history dependencies.

`deriveThemeCss(root)` calls `generateArtifacts(join(root, UI_PACKAGE_ROOT))`. That generator invokes
`assertTokenContract(uiRoot, repoRoot)` before emission. In a repository with committed history, validation
requires the removal baseline against `origin/main`; inability to read that required history throws through the
CLI as **exit 2, inability to derive**. It does not establish stale output and must not be reported as exit 1.
After successful derivation, missing or different committed CSS is **exit 1**; identical bytes are **exit 0**.
The independent reviewer drove a committed scratch repository without `origin/main` to exit 2. Rootless or
uncommitted fixtures are separate explicitly empty-history cases in `readTokenRemovalBaseline`; they do not
license silently ignoring unavailable history in a committed repository.

In normal same-repository execution, the loaded generator code and the requested data root belong to the same
checkout. A scratch root supplies token/contract data; it does not supply a new module graph. ThemeScope emit
vocabularies and `tokens.near-duplicate.ts` still come from the loaded generator package. The scratch-data
controls therefore do not prove hermetic derivation from arbitrary alternate repository code.

The independent review measured 14,857 generated bytes equal to the committed file and 203 direct declarations
at `284dedcee`. Those are dated observations, not maintained expectations. Its full comparator-cut run failed
three of five tests; the author's two failures came from a selected run with three tests skipped. Neither scoped
receipt substitutes for the whole-stage planted/cut proof, which remains owned by the coordinating primary.
