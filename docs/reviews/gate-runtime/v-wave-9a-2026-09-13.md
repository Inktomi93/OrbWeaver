## PROPOSED LESSONS

Index entries plus bodies, in the store's shape. The orchestrator owns the write.

- `- [default param ≠ pinned](injecting-a-seam-moves-the-unpinned-wiring.md) — a test that supplies the injected value never pins the DEFAULT, which is what production calls`

  **Injecting a seam to make wiring provable moves the hole to the default parameter.** The #2238 fix
  turned `resolveEvidenceErrors(…)` at the call site into an injected `resolveEvidence: Resolver =
  resolveEvidenceErrors`, and added a test that passes its OWN resolver. Cutting the call site now reds
  (good) — but cutting the DEFAULT leaves the whole suite green, and the CLI calls `runAttest(paths)` with
  one argument, so the default IS the production path. **Why:** an arm that supplies the dependency asserts
  the parameter is consulted, never that the shipped binding is the real reader. **How to apply:** whenever
  a fix introduces a default-valued dependency parameter for testability, one arm must call the function
  with the parameter OMITTED, and the planted control is a cut to the DEFAULT, not to the call.

- `- [a rendezvous half nobody reaches](rendezvous-fixture-follower-burns-the-failsafe.md) — instrument the wait; a case whose runtime equals cap×slice is cap-driven`

  **A two-party rendezvous in a test fixture is asymmetric, and the second party usually cannot satisfy
  it.** In `artifacts.int.test.ts` the leader blocks until two in-flight markers exist and exits on the
  condition in ~1.9 s; the follower can never see two, because the leader has already unblocked and
  unlinked its own marker — so the follower burns the full 50 s failsafe on every run. The assertion still
  passed, so nothing surfaced it. **Why:** the tell was arithmetic, not a failure — the case measured 52–54 s
  against `MAX_SLICES × SLICE_MS = 50 s`. **How to apply:** when a fixture replaces a sleep with a
  condition, print the loop's exit reason (slice count + observed state) from BOTH parties once before
  believing the mechanism; and treat "runtime ≈ the failsafe" as proof the failsafe is the mechanism.

- `- [retirement census: RECORD-BY-FRAME](retirement-census-record-by-frame.md) — an archived verbatim block's present tense is not a surviving instruction`

  **A retirement census hits a third class beside INSTRUCTION and RECORD: a present-tense order preserved
  VERBATIM inside a `status: archived` frozen-record document.** `agent-doctrine-accretion-2026-08.md`
  still carries "a lane that adds a TRACKED spec regenerates the manifest in its OWN worktree" — the exact
  order `lane-standing-facts.md` was edited to retire. **Why:** the doc's own header says every block is
  verbatim as of a named sha and names the live homes, so editing it destroys the archaeology the file
  exists to hold. **How to apply:** classify by the DOCUMENT's frame before the sentence's tense; say so
  explicitly in the report so the next census does not re-open it, and make sure the live rule that retires
  it is the one an agent reads first.
