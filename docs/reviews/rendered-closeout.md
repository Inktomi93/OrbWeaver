# Rendered closeout

## Decisions

- Plugin approvals use `secondary`; removal uses `ghost`. The settings page keeps its page-level primary action.
- A member removal keeps its return target in the panel. The confirm's `finalFocus` and the roster readback share that target.
- Hiding the final plugin panel returns focus to the shell Chats main region. The shell owns the cross-pane focus address.
- The model picker already excludes Recent ids from provider groups. Keep that behavior and assert its rendered uniqueness and centring.
- The flank sentinel is measured through the complete room, against its resolved reading-floor, sidebar and gap tokens.

## Acceptance

The focused CTs enter production feature doors and use production-backed providers. Mutations and reads run on isolated server roots.
The members and suggestion cases forward events emitted by those roots through the existing socket edge helper.
Socket admission acknowledgements are scripted at that network edge; these cases do not establish server subscription authorization.
Each event supplier owns cancellation and joins its subscription before root disposal.

The accessibility suites audit production section, modal and settings registries. Loaded-state checks require the actual Admin control, served build identity and preset heading before auditing.
The form suite also audits the loaded preset detail. Registry mounting does not cover every payload-dependent dialog or signed-out authentication state.

## Consent-action wrapping

The consent action Row uses the existing `flex-wrap` layout utility. Approve stays `secondary`; Remove stays `ghost`.
[The consent layout CT](../../tests/client/features/plugin/components/consent-layout.ct.tsx) mounts the production settings content from the registry at phone and wide widths with a coarse pointer. Corpus procedures supply every pending plugin.
It checks both actions against their notice and viewport. Keyboard Tab reaches Remove, Enter opens its real confirm, and Escape returns focus to Remove.

Untouched source fails at the phone width with 79px overflow; the wide case passes. The wrapping change passes both cases.
Native red and green reports are retained in `/tmp/rendered-consent-review.fj34sG/`. Completed command output is in `/tmp/rendered-consent-red-qualified.log` and `/tmp/rendered-consent-green.log`.
Affected client and DOM-test typechecks, scoped ESLint and named-entry dependency checks pass. Their output is in `/tmp/rendered-consent-typecheck.log`, `/tmp/rendered-consent-eslint.log` and `/tmp/rendered-consent-depcruise-green.log`.

The canonical plugin label home is named in `TEST_CONSTANT_HOMES` for the existing no-copied-label contract. No production export or duplicate label is added.

## Limits

Component tests qualify rendered behavior under the application gallery pipeline. They do not qualify full browser authentication or production deployment.
Independent review, visual review and shared integration checks belong to the main session.
