## Decision

Regex scripts: THREE sources joint-attached (per-character `characters.regexScripts`, preset-embedded, owner-global `fetchOwned`) — never polymorphic. Precedence: anything mutating the SHARED prompt or canon (`USER_INPUT`, `WORLD_INFO`, persist-affecting `AI_OUTPUT`/`REASONING`) is HOST-owned, server-side, resolved under `runAsUserId`; a non-host member contributes NO shared-prompt regex. Per-user `markdownOnly` (display-only) scripts run CLIENT-side, ephemeral — they can never reach shared state. The flags ARE the tier discriminant. ReDoS: `@orb/kit/regex` holds only the seam + native default + heuristic (defense-in-depth, not a guarantee); the guarantee is the `node:vm`-sandboxed `applyReplace` with a hard timeout in `@orb/server/kit/regex` (never browser-bundled), injected at turn time — a runaway pattern throws to `onScriptFailure`, never hangs the loop.
