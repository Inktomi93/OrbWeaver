## Decision

`config.extractionMode ∈ {reliable, cheap, **folded**}` — a THIRD union member, deliberately NOT a capability-derived refinement of `cheap`: no capability flag distinguishes hosted-strong from the local 8B (both advertise tools — vLLM runs hermes), R3 scopes the fold to hosted for ACCURACY not capability, a `credential.source` branch in `domain/**` would breach the Tier-3b seal, and D108's honest-cases discipline wants the host's deliberate lever, never a secret re-route. **(1) D109-1 is now mode-scoped:** the gather's REGISTRY tools stay `[]` in every mode; `folded` mounts the 7 state tools on the character turn as TERMINAL tools, `tool_choice:"auto"` — NEVER `"required"` (0/6 narratives, §3). **(2) NEW LAW — TERMINAL TOOLS are a chat-engine primitive** distinct from registry tools: attached to the wire, never resolved to a `ChatToolSet` (so `pivotCalls` returns null and the recurse loop breaks at depth 0 — the one-call co-emission mechanism), never executed, never minted as `ToolCallRecord`s, returned raw to the contributing feature on a channel whose `null` (no terminal capability on this wire) vs `[]` (capable, none emitted) distinction is TOTAL and essential. Thread: gather `terminalTools` → TurnPrep → `runTurnPipeline` → `attachTerminalTools` → `TurnPipelineResult.terminalToolCalls` → `onTurnCompleted` → `flushTurn` → the SAME `toolCallsToExtraction`/`extractionToStateDelta` fold the round uses. Only `executeTurn` threads them (never `generateTextUnpersisted`). **(2b) The MOUNT half is PRE-COMMIT** (inside turn assembly): any pre-commit gather contribution that does I/O MUST be caught errors-as-data — a failed fold-mount logs `rpg.extraction.fold_build_failed` (loud, via the injected hook — `domain/rpg` stays logger-free), proceeds tool-less, and the flush's `null` channel runs the fallback round: a failed mount costs a CALL, never a BEAT (hardening `5fb7816a`, verifier-driven — with the null-economics totality fix \[`economics===null` → channel `null`, never a fake quiet beat] and the flush fold trimmed to ONE db read, `reachableActorRefs` one-homed under `ghostTargetRefs`). **(3) \[AMENDED, EXT-4 `9b140933`] Degrade is errors-as-data, total, narrative-inviolate, and PER-ENTRY on every vehicle:** the reliable/structured case no longer whole-object-parses — `salvageExtraction` (contracts/rpg/extraction.ts) parses per plane/per entry and itemizes `dropped: [{plane, index, issues}]` INTO the `rpg.extraction.unparseable` event (the log cannot disagree with what applied, by construction); the tool vehicles log through the one `malformedToolCalls` home (truth-repaired with D121 — the name `logMalformedCalls` above was a phantom; `contracts/rpg/extraction.ts:700` is the real one-homed predicate, as this entry's original clause below already names correctly).
