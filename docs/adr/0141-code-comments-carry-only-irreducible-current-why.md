# code comments carry only irreducible current WHY

## Context

Not recorded in the ledger row.

## Decision

A stable D-ledger anchor or named law section may accompany a self-contained constraint; a volatile document line, issue/workboard/list-item number, or mutable inventory count may not. Numeric constraints belong in constants/types/tests, and growing membership belongs in the tuple or registry that enforces it. SillyTavern, Marinara, neo-tavern, campaigns, waves, and before/after archaeology live in history/review artifacts, never production comments. The source states the present invariant directly. Enforcement is syntax-aware over comments so identical bytes in runtime strings are not findings; the production comment-density baseline is shrink-only and any intentional increase requires an explicit reviewed baseline change.
