# Bounded analysis and explicit security successors

## Context

Whole-application callable and escape closure prevents practical analyzer completion. Shared code facts and security enforcement remain required.

## Decision

Keep the shared persisted store for native symbols, bindings, references, imports, exports, schema facts and bounded local analysis. Preserve world identity, complete declared populations, currentness, atomic publication, worker release and transaction isolation.

Do not require exhaustive runtime callable provenance, arbitrary helper expansion or whole-application escape proofs for foundation completion. Unsupported general analysis returns an explicit unresolved result, never a clean verdict or invented fact. Such uncertainty is not automatically a release blocker.

Prefer existing native tools and useful partial coverage before building custom analysis. Each blocking policy states its finite claim. Concrete violations block; unsupported flows remain explicit unknowns. A partial security diagnostic does not certify complex reads or runtime authority.

Retain production authorization, native type/import restrictions and real cross-tenant controls when replacing expensive security analysis. Record the static guarantees lost. Qualify the replacement and planted negative cases before deleting the old gate. Unknowns outside the retained blocking claim are advisory, not automatic release blockers. No new query-language framework or whole-query rewrite is required by default.

This narrows D321 KEEP static claims where partial coverage is adopted; production authorization requirements remain. D323 prototype enforcement remains; its complete owner-policy acceptance no longer requires general callable closure. Stop the unbounded qualification and diagnostic campaign. Historical runs retain their original results or explicit censoring.

The test-foundation plan owns implementation order. Migrate affected security readers first; independent harness and corpus work continues.

## Consequences

The bounded analyzer and security successors are not yet implemented. Retain useful shared facts and existing enforcement until successors qualify. Replace arbitrary-depth equivalence with qualified native or partial coverage and explicit unsupported outcomes. No larger heaps, hidden population cuts, suppression growth or second fact engine.

## Alternatives rejected

Continue general callable repairs indefinitely. Hide unresolved security questions as passing checks. Abandon shared native facts or retain whole-application analysis as a prerequisite for every replacement suite.
