## Decision

The retro rebuild does NOT re-land D86's full-mode spine (the statProfile/d20-resolution/GM-seat R-chunks stay FUTURE reference in `../plans/rpg/design.md`); it lands the ratified lite-plus guided substrate. Shape (`@orb/contracts/rpg` + server `domain/rpg`, 8-slot feature): `rpg_games.mode ∈ {lite, full}` dispatched through ONE exhaustive `MODE_POLICY`, but only the LITE branch is BUILT (full = typed-refusal seams). Six tables (games/snapshots/sheets/hud_widgets/journal/checkpoints), **NO ownerId** — authority rides the chat FK chain (D18/D20/D23), never a per-row owner. The roster-∪-sheets projection IS the party (no party subsystem). Wallet + inventory FIRST-CLASS. Quests fold into the snapshot array. Journal is variant-aware with a lineage projection. Reads resolve through a 4-step snapshot-resolution ladder; **no-born-seed** — `createGame` stores NO snapshot, and a read SYNTHESIZES the born-default from config when the ladder returns undefined (keeps `rpg_snapshots.message/variant` FKs non-nullable — no schema delta, no baseline regen; pinned by a no-drift byte-identity test). Volatile writes stage in a ChatTurnId-keyed accumulator; `applyLockedPatch` is merge-clear (`{}`=no-op, `null`=leaf-clear) with a generic `KEYED_ARRAYS` element-lock registry (quests→id, inventory→id, presentCharacters→key; `actorState` is a computed-key forward-seam). **THE DELIVERY-MODEL AMENDMENT (the critical new ruling — supersedes D58/D86's "ONE chat turn, structured side-effects = D48 tools in the same recurse loop" as the DEFAULT): state extraction is a turn SEPARATE from the character's narration turn, knob-gated `config.extractionMode ∈ {reliable, cheap}` (default `reliable`).** `reliable` = a dedicated post-narration structured-output extraction turn (`runExtraction`: resolve the GAME chat's `role==="host"` connection → `executor.summarize` with `responseFormat = projectJsonSchema(rpgExtractionSchema)` → parse → `extractionToStateDelta`; a non-conforming model output → EMPTY delta, errors-as-data — canon NEVER corrupted). `cheap` = the inline D48 tool subset on the character turn, best-effort (the money-saver; "we can only best-attempt extraction"). The 7 plane shapes are authored ONCE, exposed two ways — the D48 tool defs (cheap) + the extraction structured-output schema (reliable, DERIVED from the tool arg schemas). `trackersReadOnly` keys on the RESOLVED mode's capability (cheap→`capability.tools`, reliable→`capability.output.structured`); capability ABSENT → warn + **manual-steering** (the host hand-edits every plane; still steers via the injection; NEVER a silent mode-downgrade — the plan-for-small-hardware honesty discipline). **The "canon never corrupted" invariant is STRUCTURAL, not a per-applier promise:** the assembled snapshot state is validated against `rpgSnapshotStateSchema` at the WRITE boundary (`writeStagedSnapshot`) BEFORE insert; an invalid state drops the WHOLE flush (no snapshot, no journal, no bus emit) — so no applier bug, present or future, can commit a row the read-boundary parse would reject. **Carve rulings (this session, stickler-confirmed):** (1) **Cross-tenant write-boundary rule** — every by-id host verb re-scopes the id to the resolved game (`and(eq(id), eq(gameId, game.id))`), throwing `DomainNotFoundError` (NotFound-not-Forbidden, leak-free); a 90-test-green suite MISSED this IDOR — the critical stint gets BOTH the security and code verifier reviews, and a frontier stickler pass before commit. (2) **Per-actor state key** — volatile writes on a roster member resolve to that member's canonical `character:<id>`/`user:<id>` ref (name-matched via the gather roster), NOT a `cast:<name>` mint; only genuine non-roster scene cast mints `cast:` (a write→read key mismatch is a silent dead-write). (3) **Host resolution by role** — the reliable-extraction connection + the capability verdict resolve the host by `role==="host"` (post-`acceptHostHandoff`, D64), never join order (a D19 funding violation otherwise). (4) **Turnless narrator-mint** — a hand-edit on a turnless game mints a narrator slot to key the first snapshot. (5) **Verb/test structure** — group subdirs + per-verb factory files + per-verb mirror tests; `.suite` only for cross-cutting; a flush→`getTrackerView` round-trip (not a `staging.peek()` assertion) is the critical state-loop test. The compose wires the injected chat ops (`setRpgPointer`/`resolveParticipants`/`resolveHostUserId`) at the root AFTER chat via a forward-ref delegate; `rpg.stream` is EXEMPT in the cross-tenant sweep (per-yield chat-membership gate, matching `chat.streamMessages`); `bus-producer-coverage` is the structural gate over the rpg SSE bus, as over every belted bus union.
