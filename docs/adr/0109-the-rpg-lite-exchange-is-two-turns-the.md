# The rpg-lite exchange is TWO turns (the character turn + the state round); out-of-turn model calls INHERIT the turn's resolved connection + consent; `structured` is the constrained-generation primitive; vLLM is chat-completions-only (AMENDS D108's cheap arm; proven live end-to-end both modes, commit `fc85f1c0`)

## Decision

**(1) The delivery model, final:** every rpg-lite exchange = the **CHARACTER TURN** — the `{{char}}`'s prose reply, ALWAYS tool-less (the gather returns `tools: []` in EVERY mode; the reminder injection steers, it never mounts tools) — followed by the **STATE ROUND** — a dedicated post-commit model call at `flushTurn` that writes tracker state. `config.extractionMode ∈ {reliable (default), cheap}` picks the round's VEHICLE, never its existence: `reliable` = a structured extraction (`responseFormat` = the projected `rpgExtractionSchema`) routed by `conn.api`; `cheap` = a TOOL ROUND (the state-tool subset + a `no_changes` escape tool, `tool_choice: "required"`, a state-focused prompt — parallel calls on array-wire backends), folded via `toolCallsToExtraction`. Both arms fold to the SAME `RpgStateDelta` and the SAME flush. D108's "cheap = inline tools on the character turn" is DEAD (owner: prose + tools in one generation was never the intent — that combined shape is the deferred mode-3, and its future home is group chat's narrator seat, not lite). Terminology is law: it is the CHARACTER turn — lite has no narrator; "narration" belongs to the narrator seat. **(2) THE CONSENT-INHERITANCE PRECEDENT (stickler F1 — general law, not rpg-local):** ANY out-of-turn model call fired on behalf of a committed turn — the state round today; compaction/memory/expressions-class calls tomorrow — MUST ride the triggering turn's ALREADY-RESOLVED connection + ENFORCED consent verdict: the engine passes `RpgTurnContext {connection, ownerConsented}` (renamed from `RpgTurnConnection`, truth-repaired 2026-08-03 with D121 — `contracts/rpg/extraction.ts`/`domain/chat/contract/context.ts:541`; the character turn's `resolveChat` route + its `resolveTurnPolicy`/consent verdict) through `onTurnCompleted → flushTurn → the round`. NEVER a second hand-rolled `resolveRole`; NEVER a force-stamped `ownerConsented: true` (that bypass let member-triggered game turns bill the owner's sub with policy OFF — invisible to 244 green tests because the composed-real fakes made both seams identical; composed-real tests MUST NOT fake the consent seam). Reuse the VALUE, not just the function (the FOREIGN-inputs-seam shape). Fail-closed: a member-triggered non-consented sub turn throws PRE-commit, so no round fires; the round also gates on `deriveTrackersReadOnly` (no round on a capability-absent connection). **(3) The FLUSH BARRIER + freshness honesty (owner rulings):** reliable's one-beat lag is ACCEPTED — WITH a visible freshness indicator (the panel shows what beat the state is as-of; a transient updating state between turn-commit and flush, bus-driven). The barrier (`packages/server/src/domain/rpg/flush-barrier.ts`): a per-chat SET of in-flight flush promises; `awaitInFlight` blocks the NEXT gather until ALL settle; registration is SYNCHRONOUS (before any await — or an immediate re-send beats the lookup); a bounded engine-client timeout guarantees settlement (a hung flush must NEVER leak a permanent barrier entry). This is the "one-beat-behind but GUARANTEED" contract. Reminder DELIVERY is a knob beside `extractionMode` (the in_chat depth-0 injection row vs an ephemeral append to the user-message tail — both assembly-time only, NEVER persisted) so steering placement is A/B-testable. **(4) The `structured` PROVIDER ROLE (split from summarize — owner: "summarize is just ONE part"):** `structured` is the first-class schema-constrained one-shot PRIMITIVE (a `TASKS` member — `PROVIDER_ROLES` when this was written; own observability tags `api:"structured"`. **AMENDED 2026-09-19**: the per-role dispatcher file and the hand-kept firewall row are gone — the task dispatches through the one `structured` method of `packages/inference/src/roles/executor.ts` over `packages/inference/src/registry/dispatch.ts`, and WHICH wires serve it is derived from `WIRE_DEFS[…].serves`, where the subscription wire now serves `structured` too, not excluded). `summarize` means SUMMARIZATION again. The `RoleClients` facade routes by intent (`responseFormat` present → `structured`) so callers stay honest without churn; rpg extraction rides `structured`, never summarize. **(5) The 6-MODE CONNECTION CANON (the agent-sdk×vllm skin is RETIRED):** vLLM is chat-completions-ONLY — its openai-compat wire (xgrammar guided decoding + hermes parallel tool calls) strictly dominates the SDK loop against a local engine (the SDK structured path hung the 8B on the big nested schema; guided decoding handles it in seconds). Valid modes: agent-sdk × {max-pro-sub, openrouter} · chat-completions × {openrouter, vllm, custom_openai} · responses × openrouter. A stored agent-sdk×vllm connection row gets a VISIBLE error/heal — never a silent convert. **(6) The SCHEMA-AUTHORING LAW + per-call ref enums:** extraction ref fields carry a per-call ENUM of the actual roster ∪ cast keys (`constrainExtractionSchema` — mis-targets become UNREPRESENTABLE under enforcing backends; the enum MUST include cast keys or scene NPCs become unremovable); xgrammar does NOT enforce nested-array `required`, so `journal[].title` is optional + server-derived (`journalTitleFor`). STANDING RULE: every NEW schema is authored strict-style (required + nullable, never optional-by-omission) so the omission class is never born again. **(7) Observability is TOTAL:** extraction failed/unparseable/empty/phantom + flush.dropped + barrier_timeout are all logged — a state write can fail only VISIBLY; a delta resolving to zero renderable writes is a logged phantom, never a silent empty panel. Homes: the engine hook → `domain/rpg/chat-ops/index.ts onTurnCompleted` → `chat-ops/flush.ts` → `entry/compose/rpg.ts` (`buildRunExtraction` routes by `conn.api`; `runToolRound` for cheap); the barrier `domain/rpg/flush-barrier.ts`; the task split `packages/inference/src/roles/executor.ts`. Proof + review: 5 live observation rounds to both-modes green; `docs/history/reviews/stickler/2026-07-27-w4-batch.md`.
