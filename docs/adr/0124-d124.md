# D124

## Context

Not recorded in the ledger row.

## Decision

*Hand-written rpg state lives off the message plane.* `rpg_snapshots` is two-armed, pinned by `rpg_snapshots_arm_check`: a **turn row** carries `message_id` + `variant_id` NOT NULL and `as_of_message_id` NULL, and is written **only** by the turn flush — a snapshot is variant-keyed **iff** that variant's own turn produced it; a **hand row** carries both NULL and orders by the nullable `as_of_message_id` FK (`ON DELETE SET NULL`), and covers all seven hand doors' clone-forward, `resyncFromStory`, `populateFromCharacter` and checkpoint restore. `variant_id`'s unique index becomes PARTIAL (`WHERE variant_id IS NOT NULL`). Ladder order — (as-of seq, hand-after-turn, createdAt, id) — is one-homed in `domain/rpg/persistence/snapshots.ts`. `postNarratorMessage` **refuses a blank post** (checked on the assembled body, so media-only survives): the content-less canon row is unrepresentable at the write boundary, not filtered downstream. **Amends D108**: its non-nullable-FK clause and its "no schema delta, no baseline regen" cost argument were properties of that decision, not eternal; the baseline is squashed + regenerated (pre-launch, dev DBs regenerate). **Moots D111 W-A**: "state-anchor slots render silently by construction" has no subject — the slots are gone and the render filter is deleted. **Retires** the `Spine-Identity-and-Auth.md` §2e register line recording the empty slot as by-design. Retired debt: 7 filters (F1–F7) and 8 leak planes (L1–L8), the Group/model=None attribution on hand writes, and the never-delete-an-anchor footgun (a deleted as-of slot now degrades ordering, never state).
