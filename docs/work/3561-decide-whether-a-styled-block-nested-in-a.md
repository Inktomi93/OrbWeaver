# Decide whether a styled block nested in a plain wrapper is a model panel

## What

A styled block inside a centre wrapper, and a class-only block holding styled spans, do not frame; their styles drop on the plain path.

## Why

The owner ruled that model HTML frames like script HTML, and these shapes miss it.

## Done when

A ruling, then a kit row for each shape.

Filled at landing: what ran and where its output is.
