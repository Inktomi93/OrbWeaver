# A LiteRouter image refusal shows the provider's words

## What

A refused LiteRouter image request shows only a bare label.

## Why

A chat refusal on the same provider shows the provider's scrubbed words, which tell the user what to change.

## Done when

The image refusal shows the provider's scrubbed words as a chat refusal does, with a case.

## Evidence

Filled at landing: what ran and where its output is.
