# Plugin macro links and resolution edge cases

## What

A never-settling macro delays its own plugin's sibling macros. The diagnostics drawer lists a legacy alias as its own registered entry. Automation rule fields offer no macros, which under-offers builtins. No client screen shows the stored turn macro slice that VariantWireView\.macros carries.

## Why

Each is a small gap in the macro work that the first pass left outside its scope.

## Done when

A stalled macro leaves its siblings on time, an alias shows beside its macro, automation fields offer what resolves there, and a host can see a past turn's macros on a screen.

## Evidence

Filled at landing: what ran and where its output is.
