# Framed panels sit flush against prose and against each other

## What

Inside a reply frame an HTML block has no block spacing against the paragraphs around it or against the next block.

## Why

A panel looks crowded where a paragraph in the same place would have space.

## Done when

HTML blocks in a frame run take the same block rhythm as paragraphs, from tokens.

## Evidence

Filled at landing: what ran and where its output is.
