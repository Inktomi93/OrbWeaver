# The script notice names the character setting for a character that turned scripts off

## What

For a character stored with no HTML tier and interactive off, under an Interactive install default, the framed script notice names the install setting and its admin remedy, where the character setting is the cause. Only a direct API write stores that pair; the posture is correct.

## Why

The notice sends the reader to a setting that is not the reason.

## Done when

The notice names the install setting only when the character inherits the interactive half, and the framed script notice cases include that pair, red before the fix.

## Evidence

Filled at landing: what ran and where its output is.
