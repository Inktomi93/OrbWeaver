# Decide whether a single slot's empty line is a muted line

## What

Several features still draw a gloss or body Text where a read came back empty for one slot rather than a list: the image provenance strip, the dossier ask answer, the deep-compare narrative, the greeting preview, the image edit and imagine dialogs, and the connection reachability line. The MutedLine header names the empty branch of a list; these are not lists, so the migration left them, and the census cannot see them because they are null-gated.

## Why

Without a ruling the same receded sentence reads at the gloss step in these panes and at the quiet step beside them, which is the drift the owner exists to stop.

## Done when

A ruling in the MutedLine header says whether a single slot's empty line takes the owner, and the sites follow it.
