# List a provider's models as soon as a key is pasted

## What

In Add a connection and the connection editor, fetch the model catalog when a key is pasted or a saved key is chosen, without a separate List models press. For a provider whose catalog is public, such as OpenRouter, list before any key is entered.

## Why

Seeing what a provider offers takes four steps today: open the dialog, pick a provider, paste a key, press List models.

## Done when

Picking OpenRouter shows its catalog with no key; pasting an OpenAI key shows OpenAI's catalog with no extra press. A test pins the keyless OpenRouter list and the list-on-paste trigger.

## Evidence

Filled at landing: what ran and where its output is.
