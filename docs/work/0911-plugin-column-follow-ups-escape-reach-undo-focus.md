# Plugin column follow-ups: Escape reach, Undo focus, entry glide, exact-pixel CTs

## What

From the verifier pass on items 842 and 874 (plugin column, overlay, phone Plugin panels). Suspected from code, not reproduced: (1) Escape closes the overlay only when document.activeElement is inside the column or its control (packages/client/src/features/chat/hooks/use-flank-presentation.ts, useOverlayDismiss), so it does nothing for a key press inside a plugin iframe, after a mouse click in Safari, or after a click on a non-focusable part. (2) With two plugins, pressing Undo in the hide toast counts as an outside press, closes the overlay and leaves the column inert (features/chat/components/room-flank.tsx), so the restore focus in features/plugin/components/plugin-anchored-surfaces.tsx lands on body. (3) On room entry with the column collapsed, the first commit has host panels off, so a flank FLIP stamps out with the full column distance while the thread only narrowed by the control reserve; rows may glide the wrong way at mid widths (use-flank-track-flip.ts, shell.css flank track delta). Test debt: the chat-anchors CT, a [restoration register](../plans/restoration-register/design.md) entry, uses exact toBe on fractional coordinates near lines 685 and 794, which flaked on a loaded box (use toBeCloseTo); the plugin story registry in tests/client/features/plugin/\_ct-stories.tsx is a hand-picked list rather than the production chatSurfaceContributors from compose/authed-app.tsx (Spine-Testing section 10).

## Why

Keyboard exits and focus return are accessibility contracts; the CT flake and the hand-picked registry let regressions pass or fail at random.

## Done when

Each of the three suspicions is reproduced and fixed or shown not to occur, the two exact-pixel assertions tolerate subpixel layout, and the plugin stories build their registry from the production list.

## Evidence

All three suspicions reproduced and fixed. Test: `tests/client/features/plugin/components/flank-overlay-exits.ct.tsx` through the production shell and room with two synthetic sidecar plugins (3 failed on the old source for the stated reasons, 3 passed after; Chromium).

- Escape. After a press on a part of the column that takes no focus, focus lands on the shell's `tabindex="-1"` room target, so Escape did nothing. `useOverlayDismiss` in `packages/client/src/features/chat/hooks/use-flank-presentation.ts` now also closes on Escape when focus is on the body or a programmatic focus target, and still hands focus to the control. Focus on a real control or field outside the overlay still keeps its own Escape. A key press inside a plugin iframe never reaches the host document; no host change can fix that, so it needs the plugin frame to forward Escape through the guest protocol (not built).
- Undo. A press in the toast region counted as outside and closed the overlay, leaving the column inert; the overlay now treats the notice region (`toast-viewport`) as inside. After Undo the overlay stays open and the restored panel's Hide takes focus.
- Entry glide. `useFlankTrackFlip` (`packages/client/src/features/chat/hooks/use-flank-track-flip.ts`, called from `packages/client/src/features/chat/surfaces/chat-room-surface.tsx`) no longer stamps a glide when the change is the host's panels arriving or leaving; a room entered with the column collapsed stamped `data-flank-flip="out"` on arrival.

Closed as gone:

- Exact-pixel assertions: the chat-anchors CT no longer exists in the tree (`tests/client/features/chat/anchors` holds only the join-invite suite; no `chat-anchors` file under `tests/`).
- Plugin story registry: `tests/client/features/plugin/_ct-stories.tsx` mounts the production Extensions content through `useSectionRegistry`, and `tests/support/browser/ct-door.ts` builds from `chatSurfaceContributors` (`packages/client/src/compose/contributors.ts`).

Oracle Deck comment fixed in `packages/showcase-plugins/bundles/oracle-deck/main.ts`; `manifest.json` is 1.1.9 and `packages/showcase-plugins/release-entries.json` is regenerated by `pnpm --filter @orb/showcase-plugins build`.
