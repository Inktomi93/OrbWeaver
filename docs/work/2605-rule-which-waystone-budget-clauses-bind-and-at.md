# Rule which Waystone budget clauses bind and at which window sizes

## What

With a scene set the Waystone band is over the chrome share clause in D119 at the common desktop widths; with no scene the chrome is just over its ceiling on a small desktop window; and a mid-width desktop does not reach the focal stone size the panel context step's token description promises. D119a restated the budget as two cases without saying whether the chrome clause or the reference geometry still bind. Measurements: the Waystone ladder review under reports/ux-reviewer.

## Why

Measured departures have no ruling to judge them against.

## Done when

D119 states which clauses bind and at which geometry, the token description matches the render or the container query is measured against the pane, and each departure is fixed or recorded as accepted with its reason.

Filled at landing: what ran and where its output is.
