# Give Home one primary start action

## What

Make starting a new chat the single most prominent action on Home. Today New chat is a small text link under the Start with tiles, with less weight than All characters. Review whether the Elsewhere in the house chips earn their place beside the rail that holds the same destinations.

## Why

A first-time user on Home sees six sections of equal weight and no clear first step.

## Done when

Home shows one primary New chat control above the fold at phone and desktop widths, and a ux-reviewer pass on Home reports no finding on the start path.

## Evidence

Filled at landing: what ran and where its output is.
