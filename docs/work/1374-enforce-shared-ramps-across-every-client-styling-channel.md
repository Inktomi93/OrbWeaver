# Enforce shared ramps across every client styling channel

## What

Close confirmed styling escape routes in all client tiers, static JSX spreads, selected local tables and alternate class-bearing props. Strengthen the retained class, text and style rules for supported local syntax and vendor styling APIs. Migrate the exposed consumers with the pinned codemod kit. Replace standalone CodeMirror, textarea, theme-default, icon and chart design inputs with canonical ramp-derived choices.

## Why

A direct className-only rule leaves equivalent styling hidden in other carriers. Named local constants and one token per escaped literal would preserve competing design scales rather than create consistency.

## Done when

Planted bypass controls fail and legitimate runtime measurements pass. The all-client and supported vendor-style populations pass native lint without baselines or suppressed real findings. Mechanical changes use tested codemods with independently checked previews; semantic choices have explicit source-based decisions. Icons retain their distinct ink-box and optical-stroke meanings. Charts use one coherent token-backed size and typography policy with matching measurement and paint. Preserve owner CSS and data geometry boundaries. Qualify affected theme, font-scale, fit and interaction behavior through production-mounted tests and visual review. Investigate the concrete coarse small-font hit-floor question without conflating project policy and WCAG. Keep the low-priority browser-score matrix outside this assignment.
