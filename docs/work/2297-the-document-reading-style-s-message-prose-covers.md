# The document reading style's message prose covers More message actions at 200% text on the phone

## What

In the document style at 200% on the phone the message prose shares a grid cell with the action row, and its subtree takes the pointer over More message actions.

## Why

A phone user at enlarged text cannot open a message's actions in the document style.

## Done when

More message actions is clickable at 200% and 300% on chromium-phone-portrait in the document style; its original canon reading case passes the copy and delete step there.

Filled at landing: what ran and where its output is.
