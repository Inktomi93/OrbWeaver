# Separate capability from status on a connection row

## What

The Can do chips on a connection row mix capabilities (Chat, Utility model) with status (Background work off) in one chip style. Show what the connection can serve apart from which roles it holds and whether background work is on.

## Why

A Utility model chip on a connection that is not the Utility model reads as an assignment.

## Done when

The row shows capabilities, held roles and background state as distinct elements, and a CT pins a connection that can serve Utility but does not hold it.

## Evidence

Filled at landing: what ran and where its output is.
