# The no-model notice and its door appear twice on the preset editor

## What

With no chat model, the Params content and the context panel both show the same No model is set for chat yet notice, each with its own Open Connections button. The Quality dial's gloss also refers to knobs that are hidden in this state.

## Why

One message with two homes on one screen adds noise and two identical doors. The gloss points at controls the user cannot see.

## Done when

One notice with one door shows. The context panel states the state without a second door, and the Quality gloss reads sensibly with no model.

## Evidence

Filled at landing: what ran and where its output is.
