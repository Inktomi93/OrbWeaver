# Qualify the surface walkthrough on native macOS, Windows and real iOS

## What

The walkthrough claims Linux, macOS and Windows functional support and owner-clone custody differs per OS, but only Linux has run. Real iOS swipe, overscroll and keyboard behavior were never tested; desktop WebKit emulation does not prove them.

## Why

Portability and mobile gesture claims stay unqualified until run on the real platforms.

## Done when

Synthetic journeys and controls run on each claimed OS with results recorded, or the claim is narrowed in the plan; iOS gesture behavior is tested on a device or explicitly listed as unqualified.

## Evidence

Filled at landing: what ran and where its output is.
