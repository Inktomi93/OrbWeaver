# Re-mint the cited reserved decisions

## What

Write ADR files for the cited reserved numbers with their original meanings from the owner. The sites whose comments claimed the checker are listed under M21 in the missing-checker list under reports/law-census.

## Why

A reserved-window cite resolves to a number, not a ruling, so a reader cannot open it.

## Done when

Each cited reserved number has an ADR file and the window covers only uncited numbers.

## Evidence

Filled at landing: what ran and where its output is.
