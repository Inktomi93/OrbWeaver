# The guessed-limits state over-explains and its door lands above the field

## What

With guessed limits, the Output cluster says the limits are a guess in each hint, in each row note and in a notice, and tells the user to set the real limits more than once before its one door. The door opens the connection editor with Advanced expanded, but focus lands on the back button and the context-window field sits below the first screen.

## Why

Repetition buries the one action, and the door does not take the user to the field it promises.

## Done when

The row notes stop repeating the set-the-limits instruction that the notice and door carry. The door scrolls to and focuses the connection's context-window field.

## Evidence

Filled at landing: what ran and where its output is.
