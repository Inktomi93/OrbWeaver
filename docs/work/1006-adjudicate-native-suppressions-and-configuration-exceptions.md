# Adjudicate native suppressions and configuration exceptions

## What

Investigate every native suppression directive and configuration exception. Separate proven native limitations and supported scope from stale exclusions and real findings. Use the closed inventory to define cohesive repairs without weakening behavior.

## Why

Existing comments, grants and exclusions do not establish that a bypass is still necessary or correctly scoped.

## Done when

Every observed entry has source evidence and a retain, remove, fix or unresolved decision. Range and closing markers are paired. Generated repetitions are deduplicated. Repair batches name actual defects, scope and affected checks; no unexplained exception is treated as authority.

## Evidence

The source audit has a frozen checkpoint and explicit unresolved proof questions. Source-proven native exception cleanup is assigned separately; the remaining entries are not cleared. Preserve runtime behavior, retain verified limitations and repair real findings before removing their directives. The review mirror drops CSS directives while retaining governed declarations; that instrument defect remains separate from suppression legitimacy.
