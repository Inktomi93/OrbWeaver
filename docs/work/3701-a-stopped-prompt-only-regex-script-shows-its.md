# A stopped prompt-only regex script shows its stop mark on its own row

## What

The regex stop mark and reason render only in the On screen roster, so a prompt-only script that stopped has no mark anywhere the notice's action can land.

## Why

The notice names a script the reader cannot find marked in the panel.

## Done when

The stop mark and reason also render on the script's tier row, and a CT covers a stopped prompt-only script.

## Evidence

Filled at landing: what ran and where its output is.
