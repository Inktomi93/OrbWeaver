# The dialog census counts modal popovers

## What

Anchored popovers that trap focus and carry input are kept by ruling as a different shape from a centered dialog, but no census cohort lists them.

## Why

A kept class nobody counts grows unseen.

## Done when

pnpm ui-facts prints a modal popover cohort with every site and its trigger.

## Evidence

Filled at landing: what ran and where its output is.
