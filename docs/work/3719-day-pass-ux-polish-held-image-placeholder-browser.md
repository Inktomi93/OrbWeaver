# Day-pass UX polish: held-image placeholder, browser regex notice action, notice height with the keyboard open

## What

The held-image placeholder has a fixed size and hides the image alt text; the browser-side regex stop notice has no Show this script action; with the phone keyboard open a notice covers a large share of the visible chat.

## Why

Each leaves the reader with less than the screen could show.

## Done when

The placeholder takes the image's size and shows its alt text, the browser regex notice offers Show this script, and a notice with the keyboard open stays compact, each with a CT.

## Evidence

Filled at landing: what ran and where its output is.
