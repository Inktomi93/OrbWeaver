# The handle-key Unicode table can be regenerated

## What

`packages/kit/src/handle-key/unicode-data.ts` is marked generated by a command that is deleted, and `docs/adr/0257-handles-compare-on-one-unicode-key.md` names that command in the present tense. `tests/kit/handle-key/unicode-version.repo.int.test.ts` pins the table to the runtime's Unicode version. `packages/kit/src/evidence-window/index.ts` holds the package's one cross-module relative import. Source: `reports/codebase-review/units/kit.md`.

## Why

The test turns red at the next engine Unicode bump, and no command can rebuild a file nobody may hand-edit.

## Done when

A script under `scripts/` rebuilds the table from the pinned sources in the file header and reproduces the committed file byte for byte. The header and the ADR name it. The relative import uses the package's subpath form.
