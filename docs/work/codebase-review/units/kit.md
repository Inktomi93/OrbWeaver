## Findings

- \[P2] `packages/kit/src/handle-key/unicode-data.ts:1` — "GENERATED by the retired verify CLI's
  `baseline unicode-handle-key`; do not hand-edit": the generator was deleted with the verify
  CLI (821e8f8dff, the owner-parked verify-system removal) and no successor
  door exists — `rg -iln unicode` across `scripts/` and `tooling/src` is zero (dir-scanned;
  second method: name-grep `unicode-handle-key` finds only this file and `docs/adr/0257`, whose
  present-tense "`baseline unicode-handle-key` vendors the case folding…" is now false). The
  table feeds `users.handle_key` keys (D257), and `tests/kit/handle-key/unicode-version.repo.int.test.ts`
  hard-pins it to `process.versions.unicode` — green today only because this engine is 17.0.
  The day the runtime moves to Unicode 18 the test goes red, the table may not be hand-edited,
  and nothing can regenerate it. Direction: the four sha-pinned source URLs are in the file
  header — a ~30-line script under `scripts/` restores the door; re-point the ADR verb; the
  pin-test then doubles as the door's proof.
- \[P3] D141 archaeology cluster across kit (cross-cutting, not kit-only): 23 files carry
  date-stamps/`measured 2026-…` notes (worst: `card-frame/index.ts` — "TIER-B TRUST REVIEW,
  2026-08-16 (security-executor pass, #91)" plus three `measured …` section headers, and the
  same shape in ids/time/theme-derivation/strings), and 34 files / 136 lines cite issue/board
  numbers (`#854, follow-up to #837`), which comments.md rule 40 forbids outright. The facts
  are load-bearing, the formats are illegal; a rewrite-in-place sweep (keep the claim, drop
  the dig) is mechanical and belongs tree-wide at triage, not per-unit here.
- \[P3] `packages/kit/src/evidence-window/index.ts:1` — `import … from "../time/index.ts"`: the
  only cross-module relative import in the package; all 20+ other cross-module edges go through
  the `#name` subpath imports. A one-character-class drift, but it is the shape that silently
  survives a folder move differently than the `#` form.

## Verdict

reviewed (3: one P2, two P3; one comment FIXED in-unit). kit is the strongest package so far —
purity is real and provable, the suppression count fits on one hand with each reason true, and
the test mirror proves the scary claims (every-split-point scrubber sweeps, digest recomputation,
both-direction brand tests) instead of padding. Its one P2 is the sweep's thesis wearing a new
costume: the generator sentence in a GENERATED header is machinery-shaped prose — nobody reads
it until the day it must be true, which is the day the runtime's Unicode moves and the pin-test
red-faces a file nobody is allowed to edit. The deleted-verify-CLI program left this trap
behind: it retired the tool but not the tool's name in the header, and the ADR kept the present
tense.
