# Macro browser names and links each macro's real source

## What

Keep MacroSourceRef.id and show each macro's real source wherever macros are offered. Authors see macros in the macro browser and in the completion popover on the preset, game, persona, character, greeting and imagery editors; suggestions drop the source today, and plugin macros reach neither. Carry the source into suggestions and give the client the plugin macro names, with the game and member projections kept to names the viewer may see.

## Why

With several plugins installed, a generic label does not say where a macro lives. The source reference was built for this and never finished.

## Done when

The browser and the completion popover name each macro's preset, game or plugin source and the browser links to its editor, plugin macros complete wherever they resolve, an unreachable source shows the name with no link, and a room member sees no private source name.

## Evidence

Filled at landing: what ran and where its output is.
