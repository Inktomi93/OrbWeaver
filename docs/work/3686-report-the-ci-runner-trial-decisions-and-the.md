# Report the CI runner trial decisions and the default-branch workflow registration limits

## What

The workflow feedback batch asked for a written report of the runner trial decisions and of the limits on registering a workflow from a non-default branch. No such report exists in docs or reports.

## Why

## Done when

A docs path holds the runner trial decisions with the measured reason for each, and the default-branch registration limits with how a new workflow is first run.
