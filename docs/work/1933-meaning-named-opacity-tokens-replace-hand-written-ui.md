# Meaning-named opacity tokens replace hand-written UI opacity values

## What

Mint meaning-named opacity tokens beside receded, for disabled, loading, hover and any other real role, and move UI recipes and sheets onto them. Animation keyframe waypoints stay as they are.

## Why

The opacity family is named by meaning, and a numeric ramp would return to picking a number. Keyframe values are animation curves, not design values.

## Done when

No recipe or UI sheet writes a numeric opacity outside the family, and the census reports keyframes as a coded keep.

## Evidence

Filled at landing: what ran and where its output is.
