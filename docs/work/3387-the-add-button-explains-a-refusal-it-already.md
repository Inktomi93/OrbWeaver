# The Add button explains a refusal it already knows

## What

With a refused key, Add stays enabled with no description, and the refusal shows only after the press.

## Why

A keyboard or screen reader user reaches Add with no reason attached.

## Done when

Add carries aria-describedby to the refusal while the key is refused.

## Evidence

Filled at landing: what ran and where its output is.
