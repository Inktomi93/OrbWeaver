# The import preview counts switched-off scripts apart from attached ones

## What

The preset import preview says all scripts are attached while some are imported switched off, and the reason sits below the fold.

## Why

A user expects every attached script to run and finds some do not.

## Done when

The preview states how many scripts import switched on and how many switched off, with each switched-off script named with its reason in view at desktop and phone widths; a CT pins the counts.

## Evidence

Filled at landing: what ran and where its output is.
