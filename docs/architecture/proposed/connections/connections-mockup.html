The server piece getModelsForSource

One authedProcedure.query that reads snapshots + config only — never an outbound fetch, so the SSRF/CSRF posture stays exactly where it is (probes remain on the existing mutations). It unions the OR catalog snapshot, the agent-sdk shortlist, the vLLM/local config sets, and the last custom-endpoint probe — returning a normalized list per source plus a state (ok / empty / needs-key / needs-probe) and an auto-fill hint. The client picker becomes one clean call, cached per source.

What this fixes vs. today

✓No more typing model names. Every source resolves a real list; free-text survives only as the custom-endpoint fallback.
✓Your self-hosted models finally show up. vLLM + local-light are config today — invisible to the client; now they auto-fill by role.
✓Metadata at the point of choice — context window, price, modalities, alias resolution. You pick informed, not blind.
✓Source change resets the model — no stale claude-* id silently riding a flip to vLLM.
✓Key health is ambient — live dots + timestamps on keys and a source-status dot per role (green = keyed & healthy, red = no key → jumps to Saved keys).
✓Scannable — fixed columns align the picker edge down all 7 rows; the Agent row live-mirrors Chat; the embed advisory anchors to the rows it's about.
Compose-only over verified primitives (command · popover · toggle-group · status-chip all exist) · one net-new client picker + one read-only server façade · the plaintext-never-leaks credential model is untouched · nothing built yet.
