One grammar, two lists: rows drill exactly like the rack. State chip (Default/Customized) + role badge only when non-system + a mono one-line preview = the scent that was invisible inside the old collapsed grid. The nudges (incl. the previously editor-less responseNudge) live beside their kin. Defaults' bytes stay PROSE-1 slots — when S2 lands host-edited defaults, the ghosts follow automatically. This list is a FIXED ENUM — no toggles, no drag, no Add (the manageable list is the RACK, prompt-rack.html; §5.0 kills the conflation). One object, one place: body + substance line, delivery, placement, triggers and override locks all live in the drill-in. The tri-state is DEAD (owner-ruled): ONE textarea — empty ghosts the built-in default, typed = custom, clear = reset (the Actions grammar); OFF is the enable toggle alone (the header switch is its sanctioned drilled-in echo). Select ≠ drill: a rack-row CLICK selects (the readout echo IS the inspect view); the chevron/Enter drills here. Structural rule: this is a MARKER — its ⋯ menu is Move only (Duplicate/Delete omitted; literals keep the full set; the pivot offers nothing and cannot be disabled). Round-3 ruling: depth and order are SEPARATE fields — INJECT AT DEPTH sits in Delivery beside the role it rides ("depth goes near whatever role it goes in as"); ORDER (the within-depth tiebreak) stays in Placement with Zone. Dotted underline = explanation on hover (depth's "0 = the tail · N = N turns back"; order's tiebreak semantics). The CONTEXT inspector and form bridge stay deleted — CONTEXT is the per-view readout (context-readouts.html).
