The waystone ↔ map tie

One circle, two zoom levels. The header waystone owns the SKY (time + weather); the Map tab owns the GROUND. The locked state shows the waystone enlarged over the fogged map at 14% — the promise is visible, the gate is honest, and the unlock reason rides the tab's title (“Maps unlock with the map arc (MA-3)”).

The MA-3 preview

Edge-to-edge region map in the viewport: known places as pins, the Lantern pinned ember (you-are-here = the ambient location), the road dashed track-gold, unexplored fog labeled honestly. The footer keeps the panel's voice: “the story clears the fog.”

Why the tab stays visible

PHASE = disabled-with-reason (CP-doc law): a locked tab teaches the roadmap; an omitted tab teaches nothing. aria-disabled keeps it focusable so the reason is reachable by keyboard.
