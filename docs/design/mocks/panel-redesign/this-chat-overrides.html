DESIGN NOTE

What changed & why

One tab, not two. The old Appearance overrides tab (which actually held prompt/scenario overrides) and the separate Injections tab are the same family — “what I’m bending for THIS chat.” Merged into one This chat tab. Frees a meta-tab.

Collapse until needed

  • Default state is zero overrides — so the four fields are compact collapsed rows (“inheriting”), not a wall of empty textareas. That was the whole “fresh ass” problem.
  • Click a row → it expands into the editor. A set row gets an ember left-edge + a one-line snippet so you can see what’s overridden at a glance.
  • Injections stay a list with add / toggle / remove — already the right shape.

Scope stays honest

  • Everything here is genuinely per-chat: field overrides, injections, background.
  • Character appearance (theme, narration color) stays in the character editor. Global appearance (chat style, portraits) stays in Settings. Neither gets dragged into the chat view.
  • Background is the one per-chat visual — kept as its own small section at the bottom, not lumped under prompt.

Open calls for you

  • Tab name: “This chat” here — or “Overrides” / “Tuning”. Icon: sliders.
  • Keep overrides + injections as separate labeled sections (shown) vs a flatter single list — I went separate so “replace a field” vs “inject at depth N” stay legible.
