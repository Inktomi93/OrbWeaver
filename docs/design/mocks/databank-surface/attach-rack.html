The kebab (host, source = This chat)

Hide from this chat
Detach from this chat

Kebab keeps mirror parity (§12.2 N3): the inline visibility toggle is repeated as a menu item. Detach appears ONLY when the source chip reads This chat — that is the only junction the host owns here. A member's Everywhere document can be hidden, never detached; saying "remove" would be a lie, which is exactly why legacy's read-only switch was wrong.
