ARM A — RATIFIED DIRECTION

Face → history → play, in one slot

The pane is modal. Selecting a character swaps the SAME list slot from the library to her history — the editor (CONTENT) and her chats (LIST) read as one statement about one character. Back (chevron) deselects and returns the picker, restoring focus to her row.

The band swaps with the pane (D66 A1/A2)

  • Picker: CHARACTERS · count + the ONE primary New (create a character).
  • Projection: back chevron + CHATS · Azarael + the ONE primary New chat — the mode decides which create the pane owns. One primary per surface per mode.

Rows are the LANDED anatomy, reused verbatim

  • Portrait (resolved via participantCharacterIds + the character-list cache), title fallback chain, one-line snippet (lastMessagePreview, member-visibility-safe), mono relative time, hover kebab (rename/star/archive/delete work from here).
  • Markers keep their text datum: ⚔ "Game chat" (labeled icon), ★ "Starred", Archived as a text badge + recede. The selected row = ember tint + 2px left bar.
  • A group room reads SHARED, not owned: multi-seat rooms lead with an AvatarStack ("The Crimson Court" — her + Sera + Niko +1); the title names the room/cast. Her pane never claims the room is hers — it claims she is in it (the D18 grammar).
  • A room she left stays (departed seats are deliberately part of "every chat you've had with her") and renders normally — the present cast carries the name line.

What this costs, honestly

  • While editing her you can't browse the library without Back (one click) or ⌘K. The ratified trade — a band toggle can be added later without unwinding anything (owner decision D2).

Zero new machinery

  • Same chat.listChats cache entry as the Chats pane (one truth, free bus-driven freshness), one shared predicate, no new store, no server change.
